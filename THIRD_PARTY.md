# Third-party sources and licenses

This repository contains real historical photographs, not current condition reports. Each photograph's author, source, license, and license link is retained in `public/data/places.json`, `photos.json`, the place inspector and Sources view. Use those licenses when redistributing photographs. Included licenses include CC0, CC BY2.0, CC BY3.0 and CC BY-SA2.0. Attribution is not removed by a build.

USDA Forest Service / NPS agency mapping is used as planning geometry. Source endpoints and mapping gaps are retained; route polylines are not surveyed navigational or legal clearance.

Leaflet is BSD-2-Clause; React is MIT; Vite and lucide-react are MIT. Dependency license files ship in their npm packages. Basemap attribution remains visible in the map. External tile providers' usage policies apply; the app does not bulk-download or cache basemap tiles for offline use.

The generated UI design concept is a design reference only. It is not a geographic source, trail map, actual scenery photograph or route evidence.
